# Logistics Data Analyst Intern – Week 1

## Project
Strategic Planning and Data Exploration in Logistics

## Objective
Design an end-to-end logistics analytics approach covering KPI definition, data preparation,
exploratory analysis, predictive analytics and optimization.

## Proposed Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle):
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains approximately 100,000 Brazilian e-commerce orders from 2016–2018
and multiple related tables.

## KPIs
- On-Time Delivery Rate
- Average Delivery Time
- Freight Cost per Order
- Late Delivery Rate
- Cancellation Rate
- Average Review Score

## Workflow
1. Data collection
2. Data integration
3. Data cleaning
4. Feature engineering
5. Exploratory data analysis
6. Predictive modelling
7. Clustering
8. Optimization
9. Reporting and recommendations
